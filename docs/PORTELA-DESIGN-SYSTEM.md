# PORTELA DESIGN SYSTEM

Preto #050505, painel #101010, dourado #B8965A, dourado claro #E1C98D, texto #F2EFE9. Manrope nos títulos e Inter no corpo; corpo 16px, controles regulares 14px ou mais. Largura de conteúdo 1180px, margens 20px desktop/14px mobile.

Botões: borda dourada, altura mínima 48px; ação principal preenchida. Foco visível dourado. Cards escuros e fotografias quadradas reais; nomes e referência como HTML. Layout móvel: duas colunas no catálogo e uma nos blocos narrativos. Dialog nativo para foco, Escape e acessibilidade.

Narrativa: disciplina → identidade → presença → produto → atendimento. Rolagem nativa, sem prender o usuário. Animação discreta; respeitar movimento reduzido. Identidade preservada, sem novas marcas, depoimentos ou métricas fabricados.
